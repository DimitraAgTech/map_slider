LLM Prompt:

I provided two map images of Colorado, one named "underlay.png", (the satellite image of Colorado copied from Google Maps), and the other one named "overlay.png" (the regular map image of Colorado copied from Google Maps). The two maps are the same size, and aspect ratio, and they represent the same rectangular territory. Create a single file self-contained web page using HTML, CSS, and JavaScript that implements a draggable vertical slider edge that can be dragged towards the right or to the left. Provide visual feedback that indicates to the user when the mouse hovers over the draggable edge so that they know when dragging becomes possible. As you drag the slider window edge, you will see the area to the left will display that portion of the "overlay.png" image superimposed (i.e. occluding the "underlay.png" image), and you will see the area to the right will display that portion of the "underlay.png" image revealed (i.e. exposing the underlay image). The two map images do not move relative to each other, so that the dragging of the edge will only occlude or reveal part of the "underlay.png" to the right of the draggable edge. The total map image area will take up 100% of the available web page screen, and the map images do not change dimensions (i.e. absolute pixel coordinates) if the web browser screen size changes. Be sure to initialize the web page to load the two files named "overlay.png" and "underlay.png" from the local path. No other elements are displayed in the browser.
